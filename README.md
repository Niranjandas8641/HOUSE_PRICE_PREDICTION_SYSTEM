# 🏠 AI House Price Prediction System

## 📌 Overview

An AI/ML based house price prediction system built using
Python, Scikit-learn and Flask.

The system predicts house prices based on property features
such as bedrooms, bathrooms, living area, lot size, grade,
location and year built.

## 🚀 Features

- House price prediction
- Multiple machine learning models
- Linear Regression
- Decision Tree
- Random Forest
- Model evaluation
- Flask web application
- Address geocoding
- Distance calculation
- Data visualization
- CSV batch prediction
- Currency display

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Matplotlib
- HTML
- CSS
- JavaScript
- REST APIs

## 🤖 Machine Learning

The following models are compared:

1. Linear Regression
2. Decision Tree
3. Random Forest

Evaluation metrics:

- R² Score
- Mean Absolute Error
- Root Mean Squared Error
